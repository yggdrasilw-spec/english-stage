# ぶんぽうラボ

英検5級を目安に、図解・例文・端末の音声読み上げ・理解度チェックを組み合わせた静的Webアプリ。基本20項目・追加4項目、166問を収録。独自に制作した教材です。公式問題・公式音声は収録していません。

公開先： https://yggdrasilw-spec.github.io/english-stage/grammar/

## 起動

このフォルダーで `python -m http.server 8978 --bind 127.0.0.1` を実行し、`http://localhost:8978/` を開きます。このフォルダー単体では `npm run build` で `grammar/dist/` に出力します。リポジトリのルートでは `npm run grammar:build` で公開用の `dist/grammar/` に出力します。`npm run grammar:check` でソースとの一致を確認できます。外部ライブラリーやAPIキーは不要です。

## 内容

- 基本20レッスン：語順、主語、be動詞、beの否定と疑問、冠詞とsome・any・many・much、複数形、指示語、所有と代名詞、一般動詞現在、三単現、一般動詞の否定と疑問、疑問詞、can、命令と誘い、現在進行形、場所・時間・方向・相手の前置詞、形容詞・副詞、接続詞、基本構文。
- 追加4レッスン：be動詞の過去、規則動詞の過去、不規則動詞、didの否定と疑問。4級へのステップとして表示。
- 例文の切り替え、変化部分の強調、語句と役割の対応図、日本語訳、通常・ゆっくり・比較再生、日本語解説の読み上げ。
- 8問または20項目チェック、レッスンごとの4問練習、語順並べ替え、音声の意味選択。出題と選択肢はシャッフル。
- 誤答ごとの説明から該当レッスンへ移動。進行中なら未出題の同項目問題を次に挿入。結果画面からは誤答項目の別問題で再確認。
- 未確認項目優先の診断、学習記録、JSONの記録保存、同じタブの再読み込み時の途中再開。

## AIとの対話学習に引き継ぐ

ホームの「AIとの学習を準備」、各レッスンの「この文法をAIと対話」、解答後の「この問題をAIと考える」、結果画面の「結果をAIに引き継ぐ」からプロンプトを作成できます。文法は複数選択・自由入力が可能。目的（理解確認／誤答の理由／応用）、音声・文字、5〜20分の時間目安を指定できます。

生成した文章を利用するAIへコピーして貼り付ける方式です。アプリ内でAIへのAPI接続や会話は行いません。音声での対話には、貼り付け先AIの音声機能を使用します。AIが音声機能を持たない場合は文字で進めるよう指示します。生成・確認はブラウザー内で行い、選択した内容の自動送信は行いません。コピーが使えない端末では全文選択とUTF-8テキスト保存が使えます。

対象は英語初学者で、日本語の理解力・推論力が高い小学5年生。幼児扱いや過剰な称賛を避け、必要な文法用語を正確に説明し、基本語彙のまま理由・比較・誤文訂正・新しい場面への応用を求めます。一問ずつ返答を待ち、誤答の理由を確認してから短く解説し、別の例文で再確認する手順です。学習効果や外部AIの指示遵守・音声品質を保証するものではありません。

学習記録を含める場合は、選択した文法の解答数・異なる問題数・最近の正答数・アプリ内の理解度目安と、最大8問の誤答（問題・実際の解答・正解・解説）を組み込みます。指定した問題と直近の誤答を優先し、その後同じ問題で正解した記録も明示します。「学習記録と実際の誤答を含める」を外すと、成績と誤答は出力しません。

今回以降の解答は選んだ内容も保存します。旧記録に当時の解答がない場合、同じタブの同一セッションの解答記録から確認できるときだけ補い、それ以外は「当時の解答は保存されていません」と記載します。一問の誤答から誤概念を断定しません。プロンプトの設定は、このタブを再読み込みしても維持します。

## 理解度表示

一問の正誤から項目全体の理解度は断定しません。3問未満は「確認中」。最近最大6問の正答率と直近の誤答を見て「ここを復習」「別の日に確認」を表示します。「身についた」は最近5問以上・正答率80%以上・異なる4問以上・2セッション以上・初回正解と最新の正解の間が12時間以上というアプリ内の目安です。合否予測・学習効果の実証ではありません。

## 保存と音声

学習結果はlocalStorage、途中の問題はsessionStorageへ保存。同一オリジンの複数タブの解答記録をIDで統合します。タブを閉じると途中の問題は失われますが、解答済みの学習記録は残ります。保存に失敗しても、その画面内では学習を続けられます。

音声はWeb Speech APIによる端末の読み上げ。英語音声の選択、自動読み上げの切り替え、停止が可能。画面遷移・タブ非表示・別音声の再生で前の音声を停止します。音声非対応時・失敗時は画面に案内します。発音は端末や音声エンジンに依存します。独立したリスニング力判定ではなく、聞いて意味を確かめる練習です。

## 編集と検証

`content.js`は教材、`core.js`は出題・判定・習熟目安、`ai-prompt.js`はAIに渡す内容と学習方針、`ai-view.js`は出力画面、`app.js`は画面・保存・音声、`style.css`は表示です。`npm test`で教材の構造、文法の反例、判定・診断・新規問題優先・記録統合・破損セッションを検証します。`npm run qa`は、このWindows環境にあるPlaywrightとEdgeでモバイル表示、学習経路、途中再開、音声呼び出しを検証します。`npm run qa:ai`は文法選択、誤答の保持、履歴の除外、コピーの成功・失敗、UTF-8保存、設定の再開、320/390/1280px幅を検証します。`$env:GRAMMAR_QA_DIST="1"; npm run qa:ai`で配信用のdistも確認できます。スピーカーから聞こえる発音そのものと外部AIとの実会話は別途実機で確認してください。
