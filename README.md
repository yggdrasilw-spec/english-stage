# English Stage — はじめての英検5級

小学5年生向け。5級に向けた746語・語句＋155表現（901項目）を収録。全項目に例文・訳と4種類の米国英語MP3があります。カードをめくり、わかる語を1操作で飛ばし、4種類の対応チェックを連続して進めます。選択式の実戦テスト3回分（各50問）も利用できます。テーマ別の見通し、準備度、学習記録に応じたChatGPT会話用プロンプトを利用できます。詳細は [COMPLETION.md](COMPLETION.md) を参照。

公開先： https://yggdrasilw-spec.github.io/english-stage/

`python -m http.server 8765 --directory dist` で開きます。HTMLを直接ダブルクリックする方式には対応しません。

- `npm test` 復習計算・技能分離・バックアップ検証

カード → 選択 → 誤答反復 → 翌日以降の復習。IndexedDBに履歴、技能別進捗、設定、中断位置を保存。設定からJSONの書き出しと検証付き復元が可能です。復元前の記録はlocalStorageに退避します。

## 学習継続のUI（2026-10-31）

スマートフォンを優先し、ホームにレベル・今日の学習・7日間の学習記録・訪問ボーナス・ミッション・バッジを配置。画面下部にホーム／ことば帳／記録／設定を固定表示し、学習中は問題のスペースを優先します。

- ことば×技能ごとに1日1回10 XP。正誤を問わず挑戦を記録し、100 XPでレベルアップ。自己申告・初回チェック・訪問にはXPを付けません。レベルは学習量であり、英語力の評価ではありません。
- 「おかえりボーナス」はアカウント不要の端末内記録です。1日1回3スター、7回ごとに10スター。休んでも受取回数は残ります。
- 1問／異なる組み合わせで5問／3技能のミッションを達成すると2／3／5スターを自動付与。既存の回答スターと合わせ、旧形式のバックアップでも保存・復元できます。
- 連続日数は実際に選択問題に取り組んだ日を集計。休んでもXPと学習履歴は保持します。既存履歴からレベルとバッジを算出します。
- 17件の自動テスト、教材・音声検証、Edgeで320／360／390／430／768／1280pxの主要画面、保存・中断再開・レベルアップ・複数タブのボーナス重複防止・日本時間の深夜切り替えを確認。スマホSafari/Chrome実機の確認は今後必要です。

参考：Duolingoの連続学習・クエスト・バッジ（https://blog.duolingo.com/duolingo-101-how-to-learn-a-language-on-duolingo/ 、https://blog.duolingo.com/achievement-badges/）、mikanの学習日数・学習量の記録（https://mikan.helpshift.com/hc/ja/3-英語アプリ-mikan/section/23-学習の設定/）。デザインは本アプリ独自です。


## 連続カードと実戦テスト

ホームを簡潔にし、カード・英日4択・日英4択・音声4択・組み合わせを中心に再構成。公式の形式を参考にした独自模試3回分と米国英語の音声75問を収録。全問選択式で、自由記述はありません。問題数、制限時間、中断保存、採点、解説・台本については [FAST_EXAMS.md](FAST_EXAMS.md) を参照。

「わかる」と仕分けた語も翌日以降に自動で理解チェックの対象になります。ホームの主ボタンから最大10問ずつ確認し、誤答・推測なら通常学習に戻します。初回説明の省略と定着の証拠を分けています。

## フラッシュカードの操作

「はじめのチェック」はカードをタップすると約0.22秒で表裏が回転します。左スワイプで次、右スワイプで前へ。前後ボタンとキーボードの左右キーでも移動できます。移動だけでは理解度は記録しません。

「すぐわかる」は約0.42秒のキラキラ演出でカードが抜け、覚えるデッキの枚数が減ります。初回説明を省いて翌日以降に選択問題で確認し、「ひとつ戻す」やことば帳から戻せます。「動きを減らす」とOSの同設定では即時に切り替わります。

最初の8枚と表示中の前後、学習セッションの直近6問の画像を先読み・デコードします。保持は最大32画像。初回の通信待ち・読み込み失敗時も意味と例文は使えます。

検証：`node scripts/qa-flashcards.cjs`（Edge、320/390/1280px。回転・スワイプ・縦ドラッグ・キー操作・二重登録防止・除外/取り消し・保存・動きを減らす設定）。

効果音：カードをめくる／送る／「すぐわかる」で抜く／選択問題の正解に、短いWeb Audio合成音を付けています。音声ON/OFFに連動し、追加ファイルの通信はありません。正解は約0.22秒のマル描画と約0.32秒のキラキラで示し、次への操作は待たせません。再描画・再読み込みで音や動きを再生し直しません。「動きを減らす」では静止したマルを表示します。

`node scripts/qa-effects.cjs` で3画面幅の正解演出・連打・再読み込み・誤答・自己訂正・音声OFF・動きを減らす設定・カード効果音・Web Audio非対応を確認できます。

通常の連続フラッシュカードにも回転・左右スワイプ・画像先読み・除外演出・効果音を適用しています。「わかる」は現在のデッキから抜け、取り消しで戻ります。翌日以降の選択問題による確認は維持します。

カードは横ドラッグの距離に追従します。短いドラッグや中断は元の位置に戻り、端のカードは抵抗を付けて止まります。次・前への移動は回転や縮小をせず左右に平行移動し、「わかる」はキラキラしながら上に抜けます。`node scripts/qa-card-drag.cjs` で3画面幅・両カード画面の追従、復帰、縦操作、中断、演出方向を確認できます。

## 起動時のキャッシュ対策

全JavaScriptモジュールとCSSに内容から計算した版番号を付け、古いキャッシュと新しいコードが混ざる起動エラーを防ぎます。コード変更後は `npm run release:entry`、公開前は `npm run validate:entry` を実行します。GitHub Actionsでも入口の整合を確認します。音声対応表はホーム表示を待たせず読み込み、遅延時も学習画面を開きます。モジュール読込失敗時は再試行ボタンを表示し、学習記録は消しません。

`node scripts/qa-startup.cjs` で旧キャッシュによる起動エラーを再現し、新しい入口での復帰と学習記録の保持、音声読込の停止、モジュール読込失敗時の再試行表示を検証します。公開URLを引数に渡すと実際のホーム・カード・初回チェックの起動も確認できます。

## かるたの適応出題

札の表示別・語別に、取れた回数、おてつき、直近の所要時間、所要時間の累計、聞き直し回数、ゆっくり再生の使用を端末に保存し、バックアップにも含めます。時間は音声再生開始から取得まで。未習・苦手な語を優先し、仕分けで既知とした語や聞く練習で定着した語は省きます。新しい聞き間違いの記録があれば再び優先します。

４枚以上から、通常音声１回・おてつきなし・４秒以内で取ることを、２日以上にまたがって３回達成した語は30日間出題しません。聞き直し、ゆっくり、停止、画面の中断、再開直後の札は定着の証拠にしません。残り３枚以下も消去法の影響があるため定着判定から除きます。出題対象がなくなっても既知語で補充しません。かるたの記録は準備度・XPとは分けます。

検証：`npm test`、`npm run validate`、`node scripts/qa-karuta.cjs`、`node scripts/qa-karuta-adaptive.cjs`、`node scripts/qa-karuta-contrast.cjs`。

「同じカテゴリでもう一回」は、未習（回答記録なし）→かるたの回答回数が少ない札の順に選び、同回数なら苦手度を優先します。回数は取得＋おてつきの累計で、札の表示別に数えます。定着・既知の除外とカテゴリは維持し、同条件の札はランダムに選びます。

かるた完了時は同じ語・同じ札表示の前回と今回を表で比較します。おてつき・聞き直しの減少、同条件での取得時間短縮、初取得を具体的に表示し、改善がある行を先に３語まで見せます。残りは折りたたみます。別の札構成の平均から上達を推測せず、速さは残り枚数・再生方法・聞いた回数・おてつきが一致し、中断がない記録同士だけ比較します。回ごとの比較記録を保存し、再読み込みでも結果は変えません。過去の比較記録がない場合は生成せず、次回から比較します。検証：`node scripts/qa-karuta-results.cjs`。
