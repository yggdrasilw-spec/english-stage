# 接頭辞を「意味を見るレンズ」にする（2026-11-09）

文章と選択問題が中心だった初版を、接頭辞そのもののイメージを眺め、単語の中にも同じ見方を発見する読み物へ変更した。例語の絵を並べる前に、接頭辞の核になる動きを大きく示す。教員が分かりやすいイメージを一貫して示すように、項目ごとの手がかりを教材側で固定する。

| 項目 | 固定した手がかり | 区別すること |
|---|---|---|
| un- 否定 | 性質に「〜ではない」の札を重ねる | 常に正反対という意味にはしない |
| un- 逆動作 | した動作から、もとの状態へ戻る | 否定のun-とは別のお話 |
| re- | スタートへ帰って、もう一度 | 無限に繰り返す演出にはしない |
| dis- | 合わない・つながりから離れる | すべて物理的な分離とはしない |
| pre- | 本番の目印より先に用意する | 何より前なのかは場面で確認 |
| mis- | ねらいから答え・やり方がずれる | 単なる反対とは区別 |
| over- | ちょうどよい基準を越える | 今回は過剰の用法。別用法もある |
| under- | 必要な目印まで届かない | 不足と下の位置を混同しない |
| non- | その仲間の外側に置く | 良い・悪いの評価ではない |
| bi- | 何かが二つ | biplaneは飛行機2機ではなく主翼が上下2組 |
| tri- | 何かが三つ | 角・色など数える対象を確認 |
| multi- | 一つから複数・いくつもへ | 特定の数に固定しない |
| sub- | 基準より一段下へ | 温度・土など基準を場面で確認 |
| super- | 普通の水準をぐっと越える | 慣用的な意味は単語全体で確認 |

これは児童向けの意味の手がかりで、接頭辞の全用法を一つの語源図で説明したという主張ではない。各お話の「先生から、ひとこと」で、そのイメージの守備範囲を示す。全語の辞書照合・教育者校閲・学習効果の実証は引き続き未完了。

## 体験と記録

1. 核となるイメージが一度だけ動く。
2. 下へ読み進めると、許可リストの例語にも同じ意味の変化が現れる。
3. 別の語を予想し、「絵でたしかめる」で実際の意味を見る。採点せず、読了の条件にもしない。
4. 好きなら次のお話へ。問題は任意で、既存の復習・正誤記録を維持する。

基本・中級の14項目は自由に読める。「イメージを見た」記録は`seen`に保存し、正解・XP・習得・復習間隔に加えない。応用・発展の確認問題は従来の解答記録に基づいて開く。bi-は出題候補がbiplaneだけなので、架空の語や保留語で例語を水増ししない。

## 画像生成とアニメーション

built-in image_genを使用し、次の5点を新規に生成した。外部サイトの図・音声・例文は転載していない。最終プロンプト全文、寸法、生成方法、確認記録は`data/image-assets.json`にある。

- `assets/guide.png`：透明背景の共通キャラクター。図の中で境界を越える・戻る・下へ進む。
- `assets/happy-pair.png`：同じ児童のhappy / unhappy。
- `assets/lock-pair.png`：同じ錠前のclosed / unlocked。
- `assets/reread-pair.png`：同じ本を読む / もう一度読む。
- `assets/overfill-pair.png`：同じコップのfill / overfill。

生成画像は目視し、顔の同一性、鍵の開いた隙間、同じ本、水が縁まで満ちてからあふれることを確認した。PNGの内容は加工せず保存。前後が上下に入った画像は、ブラウザーの表示枠で一方を見せて切り替える。その他の場面は意味を確認できる独自の図形イラストで描き、数や位置を正確に保つ。

動きは画面に入った時に一度だけ。画面から離れた・「元の絵」を選んだ・別ページへ移った場合は待機処理を取り消す。画像の準備が遅い場合は読み込みを待つ。動きを減らす設定とOSの設定を尊重し、元の絵と変化後の絵は操作で比較できる。日本語ナレーションと英単語の音声は、それぞれ端末の該当言語の読み上げを利用する。
